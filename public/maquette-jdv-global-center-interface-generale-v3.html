À propos de JDV GLOBAL CENTER

Le point d’entrée central de l’écosystème numérique JDV.

Une porte d’entrée, plusieurs univers spécialisés

JDV GLOBAL CENTER a pour vocation de rassembler et de rendre découvrables les applications de l’écosystème. L’utilisateur peut explorer les univers, consulter les fiches des services et rejoindre l’application adaptée à son besoin.

  • Le portail global organise la découverte et les accès.
  • JDV CORE mutualise les services techniques transversaux.
  • Chaque application reste indépendante dans son domaine métier.
  • JDV CRM est une application du catalogue, au même titre que les autres.
  • L’interface s’adapte aux ordinateurs, tablettes et téléphones.

Base de travail issue du dépôt GitHub

La maquette reprend les identifiants, intitulés, descriptions, routes et regroupements du registre frontend src/lib/jdv/application-registry.ts. Le registre présente 29 applications. La table Supabase public.modules avait été relevée à 19 entrées lors de l’audit précédent : cette différence doit être réconciliée avant de connecter le catalogue en production.
